Problem

Savings users lack control and transparency

  • Most savings apps hide yield logic and rebalancing decisions.
  • Users cannot choose per-goal risk and automation behavior.
  • Autonomous execution is usually opaque or centralized.
Solution

On-chain goal vaults + agentic strategy engine

  • Each goal creates a dedicated vault contract on Hedera.
  • Goal mode is persisted on-chain: Max Yield, Prized Yield, Select a Strategy.
  • Agent consumes external signals and strategy data to decide/execute rotations.
  • Manual and semi-autonomous controls are exposed in-app.
Architecture

Contracts + App + Indexer/Agent

Contracts
GoalVaultFactory, GoalVault, PrizeSavingsPool, strategies.

Frontend
Next.js + Wagmi/Viem pages: Overview, Goals, Automation, Settings.

Indexer
Tracks GoalCreated/Deposited/Withdrawn and serves activity API.

Agent
Decision API + execute API with optional Hedera Agent Kit path.

Bonzo + HAK

Bounty alignment

  • Bonzo-compatible strategy routes are represented and selectable in app/agent.
  • Hedera Agent Kit execution path is supported with AGENT_EXECUTOR=hak.
  • Manual trigger + autonomous cycle endpoint provide reproducible judge demos.

End-to-end user flow

  3. Open Automation page and run agent cycle.
